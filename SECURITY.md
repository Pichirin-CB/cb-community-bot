# Security Policy

## Supported Versions

Security fixes are provided for the latest published version of CB Community.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0    | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in CB Community, please do not
publish the vulnerability publicly through GitHub Issues, pull requests,
or other public channels.

Please report security vulnerabilities privately through the official
CB Studios support channel:

Discord:
https://discord.gg/hsx6AvBg5s

You may also use the official CB Studios documentation for additional
project information:

https://docs.pichirincb.com/

When reporting a vulnerability, please include:

- A clear description of the vulnerability
- The affected component, module, or file
- Steps required to reproduce the issue
- The potential impact
- Relevant logs or screenshots that do not contain sensitive information
- Any suggested mitigation, if available

### Do Not Include Secrets

Never include the following information in a security report:

- Discord bot tokens
- API keys
- Passwords
- Private credentials
- Production databases
- Environment files containing secrets
- Session tokens
- Other sensitive authentication information

If logs are required to reproduce an issue, remove all credentials,
tokens, personal information, and other sensitive data before submitting
them.

## Responsible Disclosure

Please allow CB Studios reasonable time to investigate and address a
reported security vulnerability before publicly disclosing the issue.

Security vulnerabilities should not be disclosed publicly through GitHub
Issues, pull requests, Discord, social media, or other public channels
until a fix or mitigation has been prepared where reasonably possible.

## Response

CB Studios will review valid security reports and determine the
appropriate remediation.

Depending on the severity and impact of the issue, CB Studios may:

- Acknowledge the report
- Request additional technical information
- Develop and release a security fix
- Provide a mitigation or workaround
- Publish security information when appropriate

## Scope

This security policy applies to the CB Community source code and
officially maintained components contained in this repository.

Third-party dependencies are subject to their respective maintainers'
security policies and release processes.
